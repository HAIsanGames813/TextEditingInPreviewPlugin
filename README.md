# プレビュー上テキスト編集
制作者:HAIsan

## 概要
プレビュー上のテキストをダブルクリックすることでテキスト編集モードに入れるようにするプラグインです

## インストール方法


##使用方法
プレビュー上のボイスアイテムやテキストアイテムのテキストをダブルクリックすることでテキスト編集モードに入れます
